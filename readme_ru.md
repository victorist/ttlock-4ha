# Управление замками TTLock в Home Assistant

[English Version](readme.md) | [Русская версия](readme_ru.md)

Данный репозиторий содержит решение для управления, создания, просмотра и удаления временных и постоянных PIN-кодов в замках TTLock через Home Assistant с автоматической проверкой доступности устройств и фактической верификацией записей в замках.

---

## 📋 Общее описание

Для управления замками TTLock используется интеграция `TTLock` (кастомный компонент `hass-ttlock`). 

Интерфейс решения состоит из четырех ключевых модулей:
1. **Карточка создания PIN-кода (`ttlock_card.yaml`)**: выводится на дашборд Home Assistant. Клик по кнопке вызывает всплывающую форму ввода параметров PIN-кода с помощью компонента **Browser Mod**.
2. **Скрипт создания PIN-кодов (`ttlock_script.yaml`)**: принимает параметры из формы, конвертирует даты, проверяет доступность замков, отправляет команды на создание PIN-кодов, запрашивает список кодов через `ttlock.list_passcodes` для верификации и информирует пользователя о статусе каждого замка.
3. **Карточка и скрипт просмотра PIN-кодов (`ttlock_passcodes_card.yaml` и `ttlock_list_script.yaml`)**: позволяют выбрать любой замок и вывести аккуратную табличную форму со всеми зарегистрированными в замке PIN-кодами, их статусом (`🟢 Активен` / `🔴 Истёк`) и сроком действия.
4. **Карточка и скрипт удаления истёкших PIN-кодов (`ttlock_delete_card.yaml` и `ttlock_delete_script.yaml`)**: автоматически находят все PIN-коды с истекшим сроком действия и удаляют их из умного замка TTLock с мгновенным обновлением таблицы.

## 🚀 Основной функционал и возможности

* **Просмотр всех PIN-кодов замка**: возможность в один клик получить и просмотреть полный список паролей замка (имя владельца, цифровой код, срок действия, статус активности) во всплывающем окне `browser_mod.popup`.
* **Удаление истёкших PIN-кодов в один клик**: автоматический подсчет просроченных кодов и вывод красной кнопки `🗑️ Удалить истёкшие (N)` прямо внизу модального окна просмотра списка или на отдельной карточке дашборда.
* **Автоматическая адаптация дат**: поддерживает передачу дат в ISO-формате и в миллисекундах (Unix timestamp) от `browser_mod`, автоматически приводя их к формату `YYYY-MM-DD HH:MM:SS`.
* **Предварительная проверка доступности (Online / Offline)**: перед отправкой команд скрипт проверяет состояние замка в Home Assistant (`states(lock_entity) not in ['unavailable', 'unknown']`). Если замок недоступен (офлайн/отключен шлюз), операция пропускается с выводом предупреждения `⚠️ Замок недоступен`.
* **Фактическая верификация (list_passcodes)**: вместо того чтобы предполагать успешность отправки команды, скрипт вызывает сервис `ttlock.list_passcodes` (возвращающий `response_variable`), считывает список существующих PIN-кодов и проверяет наличие созданного кода.
* **Автоматический каскад для связанных замков**: создание PIN-кода в замке квартиры автоматически дублирует этот же PIN-код на общий замок подъезда и калитку.

## ⚙️ Требования и зависимости

1. **Интеграция TTLock** (`hass-ttlock`): должна быть установлена и настроена в Home Assistant. Предоставляет сервисы:
   * `ttlock.create_passcode` — отправляет команду создания кода через Gateway (API `keyboardPwd/add`).
   * `ttlock.list_passcodes` — запрашивает из замка/облака список фактически сохраненных кодов (`lock/listKeyboardPwd`).
   * `ttlock.delete_passcode` — удаляет выбранный код из замка/облака (`keyboardPwd/delete`).

2. **Browser Mod**: кастомная интеграция для показа всплывающих диалоговых окон (`browser_mod.popup`) на устройствах пользователей.

## 🛠️ Установка и настройка

1. Скопируйте содержимое скриптов в вашу конфигурацию Home Assistant (например, в `scripts.yaml` или отдельные файлы скриптов):
   - [`ttlock_script.yaml`](ttlock_script.yaml)
   - [`ttlock_list_script.yaml`](ttlock_list_script.yaml)
   - [`ttlock_delete_script.yaml`](ttlock_delete_script.yaml)

2. Добавьте конфигурации карточек на ваш дашборд Lovelace:
   - [`ttlock_card.yaml`](ttlock_card.yaml)
   - [`ttlock_passcodes_card.yaml`](ttlock_passcodes_card.yaml)
   - [`ttlock_delete_card.yaml`](ttlock_delete_card.yaml)

3. Перезагрузите скрипты в Home Assistant через **Панель разработчика -> YAML -> Перезагрузить скрипты**.

### 6. Просмотр и очистка PIN-кодов замка (`ttlock_passcodes_card`, `ttlock_list_script` и `ttlock_delete_script`)

Для удобного контроля и очистки созданных паролей:

1. **Карточки вызова (`ttlock_passcodes_card.yaml` и `ttlock_delete_card.yaml`)**:
   - Кнопки на дашборде выводят форму выбора замка для просмотра списка кодов или удаления истёкших.

2. **Просмотр списка и динамическая кнопка удаления (`ttlock_list_script.yaml`)**:
   - Запрашивает данные вызовом `ttlock.list_passcodes`.
   - Выводит пароли в чистой HTML-таблице со статусами `🟢 Активен` и `🔴 Истёк`.
   - При обнаружении истёкших кодов (`expired_count > 0`) автоматически добавляет в нижнюю панель модального окна красную кнопку `🗑️ Удалить истёкшие (N)`.

3. **Скрипт удаления истёкших кодов (`ttlock_delete_script.yaml`)**:
   - Находит все истёкшие коды выбранного замка.
   - Последовательно вызывает `ttlock.delete_passcode` для каждого истёкшего ID.
   - По завершении автоматически перезапускает скрипт просмотра, моментально обновляя таблицу перед пользователем.
